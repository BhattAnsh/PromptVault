# PromptVault

A Chrome extension for scraping and organizing chats from different AI platforms like ChatGPT, Claude, Grok, and Gemini.

## Features (Planned)

- Save chat history from multiple AI platforms
- Organize and categorize AI conversations
- Search through your past AI interactions
- Export conversations in various formats

## Supported Platforms

- ChatGPT (chat.openai.com)
- Claude (claude.ai)
- Grok (grok.x.ai)
- Gemini (gemini.google.com)

## Installation Instructions

### Development Mode

1. Clone this repository
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" in the top-right corner
4. Click "Load unpacked" and select the PromptVault directory
5. The extension should now be installed and visible in your Chrome toolbar

## Usage

1. Visit any supported AI platform
2. The extension icon will indicate which platform you're currently on
3. Chat conversations will be automatically saved (in future versions)
4. Click on the extension icon to view saved chats or adjust settings

## Current Status

This extension is currently in early development. Basic infrastructure is in place, but full functionality is still being implemented.
